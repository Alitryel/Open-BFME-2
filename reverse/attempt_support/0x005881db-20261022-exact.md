## Finding

The old 2196 B bank retained the first list cursor in EBX. The retail loop reloads
it from its stack home at the head and latch. Neither a volatile cursor nor more
floating-point expression changes supply the retail shape.

The shared-tail recipe from `netpacket-tail-20261022f/readme.md` does. Give the
first loop two completion edges, with the null/disabled unit, special-AI, missing
AI and status-test exits jumping into one arm. The invalid index and special
state exits use the other completion label. Both arms copy the cursor into the
same temporary; advance that temporary once after the join:

```cpp
completeBody:
 if(force) {
advanceNode:
  next=node;
 } else { next=node; }
 node=next->next;
```

Every path advances once. The condition and copy disappear from the emitted
body. Their earlier presence changes cursor splitting and slot packing:

- Duplicating `node=node->next` in the arms gives the retail instruction stream,
  but leaves 17 differing stack displacements.
- Duplicating `next=node->next`, followed by `node=next`, reduces this to eight
  displacements: the cursor and index homes are swapped.
- Duplicating `next=node`, followed by `node=next->next`, is **2199/2199 bytes
  exact, with every relocation resolved**, using either `force`, `victim!=0`
  or `held->active` as the condition. The landed source uses `force`.

These are ordinary source-only compilations. No compiler intervention, assembly,
new symbol pins or gate changes were used. A passive c2 trace of the 17-offset
variant confirmed its pre-merge node weight was 6; no forced compiler result was
used as admission evidence.
