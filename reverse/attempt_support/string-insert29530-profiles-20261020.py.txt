from pathlib import Path
import subprocess,sys,json
root=Path(__file__).resolve().parents[1];out=root/'build/string-insert29530-helpers-oct20';results=[]
for profile in ('vc71-sp1','vc71-ddk-4035'):
    for shape in ('inline','inline_noinline'):
        source=out/(profile+'_'+shape+'.cpp');source.write_text('// compiler: '+profile+'\n'+(out/(shape+'.cpp')).read_text())
        p=subprocess.run([sys.executable,'tools/explain_mismatch.py','?bfmeDoInsertQX@BfmeThingQX@@QAEXPADID@Z','--rva','0x00029530','--size','662','--source',source.relative_to(root).as_posix()],cwd=root,capture_output=True,text=True,encoding='utf8',errors='replace')
        output=p.stdout+p.stderr;source.with_suffix('.log').write_text(output)
        summary=[s for s in output.splitlines() if s.startswith(('compiled symbol size:','first diff:','unresolved:','OK:','classification:'))]
        results.append({'profile':profile,'shape':shape,'exit':p.returncode,'summary':summary});(out/'profiles_results.json').write_text(json.dumps(results,indent=2)+'\n');print(profile,shape,p.returncode,summary,flush=True)
