# Closer bank for RVA 0x00758DE0 (w3, 2026-10-20)

Target `?bfmeTwoCGD@BfmeThingCGD@@QAEXXZ`, 333 bytes, retail extent 0x00758DE0..0x00758F2C (RET) followed by three INT3 bytes. The new bank is `reverse/attempts/0x00758de0.cpp`. It is semantically equivalent to retail (same tests, the same three prepare calls with the same arguments, the same response receivers and a reverse vector equal to the negated normal). Every earlier comment line of the bank is preserved.

These counts come from `tools/align_diff.py` with the boundary fixed at the verified 333-byte extent (a scratch wrapper that only replaces `find_boundary`, because the CLI looks for four INT3 bytes and runs into the next body at +411). The unmodified CLI gives 16/31/8 for the previous bank and 13/18/5 for the new one. Reloc differences are 0 and branch differences 2 in both. Measured as retail bytes covered by aligned, operand-identical instructions, the previous bank covers 178 of 333 bytes and the new one 255 of 333 (score 0.7658). The positional equal-offset byte count drops from 197 to 181 because the body is 9 bytes short, so that measure is not used.

## Findings

1. Retail's reverse-normal sequence is reproduced exactly by reading x and y into float locals before the reverse is written, copying z into the reverse, then storing -x, -y and negating z in place. The output is retail's 12 instructions in retail's order: `fld x; mov r,[z]; fld y; mov [rz],r; fxch; fchs; fstp rx; fchs; fstp ry; fld rz; fchs; fstp rz`. None of the twelve statement orders of direct negations interleaves the loads, presumably because the stores to the address-taken reverse block hoisting. Constructor and setter forms evaluate right to left and forward z. `/arch:SSE` emits SSE negation, so the body is x87 like `collisionmanager_impl.cpp` (`/O2 /G6`, which is inert here).
2. The `this` allocation gap is small. Two straight-line extra uses of the `&node->normal` temp (diagnostic sink stores, never a candidate) move `this` to EBX and the normal pointer to EDI as in retail; one use does not.
3. Binding each response's prepare result to a named local (`void *info = ...prepare(...); ...->respond(info);`, for the first response and the reverse response) moves `this` to EBX and the normal pointer to EDI with natural code. It also moves the outer receiver's vtable load after the inner call and lets `&node->point` live in EBP, which retail does not do.

## Hypotheses ruled out

Reading the normal through a pointer only (gives `[reg+4]/[reg+8]` addressing, `this` stays EDI). The inline table iterator built from the rowed `reset` (0x00758B60) and `nextNode` (0x00758B80) bodies (drops retail's retained null test). Inline bool predicates for the source null tests or the iterator tests (identical code). A local struct copy of the normal (three dword copies, frame 0x18). Locals for both data pointers (`this` moves to EBX, but node dies early and `&point` is spilled). An inline response helper, by reference or with the vector by value (reloads or extra copy code). A pointer to the normal held from before the state test.

## Remaining mismatch

- Test call: retail pushes `&normal` before loading the inner vtable and pushes the prepare result before reloading the receiver; ours loads the vtable first and pushes last.
- First response: retail loads the outer vtable into EBP before the inner call (single-expression form) and recomputes `&point`; ours loads it after the call and keeps `&point` in EBP.
- After the negation retail keeps `node->first` and `node->second` in EAX/EDX from the null tests and reloads only `->source`; every variant here without data-pointer locals reloads both node fields, which is exactly the 5 bytes by which the single-expression form with the exact negation (338 bytes, 13/33/8, `this` in EDI) exceeds retail.
- Reverse response: retail loads the outer vtable into EDI before the inner call.

## Next step

Find a single-expression spelling of the two responses that keeps `this` in EBX; per finding 2 that needs about two more weighted uses of the normal pointer, or less weight on `this`. Also find why retail's stores to the reverse vector do not invalidate the node field loads.
