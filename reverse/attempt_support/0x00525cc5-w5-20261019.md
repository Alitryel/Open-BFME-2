# Remaining mismatch and rejected hypotheses

Retail uses EBX for the receiver/list and EDI for ObjectID followed by cached GameLogic. The replacement swaps these roles. Its rank-loop entry compares ESI to cached EAX and its back edge repeats the memory compare plus conditional branch. Retail has one top memory comparison and an unconditional back jump. The replacement is two bytes longer. Three distinct diagnostic sink stores move GameLogic to EDI; one or two do not. Those added stores are not in the bank. This is an allocator priority gap, not evidence that such stores belong in the function.

The iterator argument fixes the previous forced temporary copy and matches retail's outgoing return slot. Value and reference conversion constructors retain extra copies. Moving the rank store into both branches recovers retail's scheduling across the frame comparison. Reusing the template local recovers ESI's template reload. Aggregate initialization worsens alignment; a value constructor adds no gain. Continue, nested while, inverted loop, shared check label, condition-chain form, postincrement and iterator reuse leave the loop rotation unchanged. Comparison by value worsens code; the stock comparison and accessor forms do not help. A list reference bound at entry changes the prologue. Binding it after the image guard does not help. Append-and-return rearranges both arms. /arch:SSE and canonical GameLogic adoption are codegen-inert. /Og- expands the body to 514 bytes. Test-position barriers change allocation without recovering the top loop and are excluded.

The bank's iterator-valued notification overload is deliberately unpinned. Its mangled name is `?Rva005258F8@Holder00525D9A@@QAEXHU?$_List_iterator@UBfmePod12@@U?$_Nonconst_traits@UBfmePod12@@@_STL@@@_STL@@@Z`; retail ABI evidence establishes RVA 0x005258F8. Exact landing must admit that declaration with pin_admission, or reconcile it with the provider's existing raw node view. No pin was added for this partial attempt. The destination resolver names Code/GameEngine/Source/GameClient/GUI/InGame/Tactical/InGameHeroSelectInterface.cpp; no nonmatching code was placed there.
