# Retail source-path evidence snapshot

`retail_paths.csv` is generated by `tools/source_layout.py` from the declared
BFME 2 1.06 `game.dat` baseline. It retains every occurrence of the **173 original
`.cpp` paths and ten header paths**, together with the raw EA string, byte offset,
string RVA, encoding and exact image SHA-256. It is evidence of path existence,
not a complete original source map or an approved body-to-file assignment.

The initial reviewed scan on 2026-10-25 found:

| Measurement | Count |
|---|---:|
| Retail original `.cpp` paths | 173 |
| Retail original header paths | 10 |
| Retail string occurrences retained, including duplicates | 185 |
| WorldBuilder paths after case folding | 1,361 |
| Combined original/donor path catalogue | 3,888 |
| Selected active source files surveyed | 23,366 |
| Rows with checked retail path-reference instructions | 282 |
| Consolidation investigation groups | 1,046 |
| Source files with no usable routing candidate | 12,263 |
| Groups cleared for an automatic merge | 0 |

The current TU map failed freshness; its assignments remain hints. The full
snapshot passed its input/output freshness check after generation. These counts
describe that snapshot, and should be regenerated as naming and reconstruction move.

The full path union, source queue, per-file packets, investigation groups,
ROTWK vocabulary and input/output receipts are generated under ignored
`build/consolidation/`. Reproduce them with:

```text
python3 tools/name_lane.py consolidate --rotwk C:\GitLab-Runner\rotwk-unofficial-202\source
python3 tools/name_lane.py consolidate --check build/consolidation
```

Omit `--rotwk` on machines without that optional data folder. To refresh this
compact snapshot after a successful scan/check, copy
`build/consolidation/retail_paths.csv` here. Do not hand-edit its contents.
`--check` applies to the full generated snapshot with `inputs.json`, not this
retail-only archive.
