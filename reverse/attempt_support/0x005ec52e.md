## The codegen wall

MSVC/7.1 assigns EDI to the mine mask only when the other element is the
first long-lived value (source computes `other.m_bfmeSecond` first). In that
shape the scheduler then issues the other word chain before the mine word
(first candidate above). If the mine word is moved first in source, the
allocator gives ESI to the mine mask and EDI to `&other`, so the exact
`and edi` block is lost.

The same two-valued split appears for every barrier position tried:

* barrier after both word loads (candidate): correct alloc, wrong load order;
* barrier after the element pointers / before the words: 106 B, `this`
  moves to ESI and the tail grows;
* barrier between the two word loads or after the mask: load order or tail
  changes;
* no barrier: 86-93 B fused form.

17-source ordering/barrier grid (`build/scratch/grid8.py`, outputs
`build/scratch/grid8/`) reproduced exactly these three outcomes.

## Ruled out in this seat

* Flag/compiler grid: `/O2` (105 B, uses ECX/EDX and pushes at exit),
  `/O1 /G7 /arch:SSE` (same as candidate), `/O2 /G7 /arch:SSE` (105 B),
  `/O2 /Os /Oa` (same as candidate).
* By-value flags accessor (`getFlags()` returning a 4-byte struct) for the
  mine side: same candidate prologue.
* Reading `other`'s element pointer through `const S4SortElem8 &`, a named
  pointer, or `&o.m_bfmeSecond`: the compiler defers the address load or
  hoists `[esi+4]`; 102-106 B, never the retail order.
* Defining `other.m_bfmeFirst` early and hoping the load sinks: it stays
  early (104 B, `mov eax,[esp+4]`).

Prior seats already ruled out the 288-variant source grid, int/bool return
forms, bitfields/unions, volatile mine reads and helper inlining
(`reverse/re_attempts.log` at 0x005EC52E, entries t=5..95).

## Next lever

A non-volatile, non-extra-instruction reason for `&other` to become the
first callee-saved value while the mine word is still issued first. The
retail stream is consistent with a source whose first read through `other`
is the *tail*'s `m_bfmeFirst` (sunk to the tail) and whose flag word read
comes from a by-value copy; nobody has found that shape yet. If a form is
found, the row belongs in a one-row TU with
`reverse/flag_overrides.csv` entry `<source>,/O2 /Os,1,1,region default
loses rows` (the region default fuses the flag pair and loses the row).
