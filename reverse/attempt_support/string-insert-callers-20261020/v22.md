  Authentic base `max_size()` forwarding and const dispatch carriers are inert.
- Ordinary depth 8 and the compiler default both reproduce 149/170 bytes.
  Removing unused methods and using the existing owner name preserve the match.
- Early and late explicit-instantiation declarations suppress the copy helper
  but change the callers to 116/131 bytes.
- Imported inline insertion changes them to 117/132 bytes.
- Imported forceinline insertion preserves lengths 149/170 but calls the
  unresolved `insertDispatch` instead of the target insertion and passes the
  false-tag slot at -5 instead of the native category-tag slot at -6.

None of the rejected emission controls is present in production. Further
link repair must preserve both the actual caller and full shared callee, not
only its byte count.
