## Reusable positive result

The ordered-write observation from the just-landed 334A0 recovery transfers to
the descriptor flag group. Writing the existing +0D, +0F, +0E byte fields in
their native order through volatile unsigned-char lvalues fixes the early +0E
true store. Ordering only +0E does not. This changes no access width, adds no
reads or writes, and does not identify retail's original qualifiers.

The old bank's prefix diverged at 32BE0. The new prefix is exact through
32C11. Our mnemonic-aligned diagnostic changes from five structural regions
and five non-relocation operand differences to three regions and three operand
differences. Those counts are diagnostics, not byte coverage. The bank score
0.985 is a ranking hint, not a percentage of verified bytes.

## Exact remaining gap

Retail: `mov edx,eax; or edx,ebx; mov eax,edx`, followed by the existing
size-mask/fencepost calculation. Candidate: `or eax,ebx; mov edx,eax`.
One two-byte MOV is missing. POP ESI/EBP also interleave differently with
loading/storing the 8-byte fence markers. Neither defect is fixed.

Binding the raw size through a reference to an assignment into header[1]
reproduces the native three-instruction copy/OR sequence, but keeps an extra
three-byte heap store; it emits 346 bytes. This diagnostic is not a match and
must not be landed. Local scalar, struct and array references remove that store
but coalesce the copy again. Aggregate pointer clearing can reach 343 bytes by
adding a second XOR-zero register; that is also not a recovery.

Independent controls: common/early/goto returns; scalar and reference lifetimes;
typed header values, copies, assignment return contracts and bitfields;
pointer-return ABI views; whole initialization and footer member helpers;
callee inline policies; real metadata clearing with memset and POD assignment;
reconciled 31010 home; authenticated 4035 and SP1 profiles; O2/G5/G7, Os/O1,
Ob1 with explicit inlining and narrow memory barriers. None closes the copy
gap. New pointer/size member reads can introduce a post-splice reload: the
compiler cannot prove that the linked node's prev store misses the descriptor.
Oa/Ow diagnostic alias assumptions do not recover it and were not retained.
This compiler rejects __restrict. Some deliberately exploratory conversions
captured an initial flag value rather than its changing storage; those invalid
controls were rejected and are not claimed as equivalent.
