## Remaining mismatch (1 region, 2 register lines)

With the reference, EBX holds the address of the player's `m_defaultTeam` (`add ebx,0x2ec` at +0x34B, `push dword ptr [ebx]` at +0x366), and the template is spilled to `[ebp-0x18]` exactly as in retail. Retail loads the team value before `memset` (`mov ebx,[eax+0x2ec]` at +0x33E, `push ebx` at +0x366). Everything else now matches: the names-loop back edge carries the iterator in ECX into the loop head, loop 1's found block sits after the epilogue at +0x530, and every stack home is retail's.

So the reference is not retail's spelling. It proves the lever: the priority that decides EBX between the template and the team depends on how the team is used, not only on how often. An address used as a memory base (`push [ebx]`) outranks the template, which a plain pushed value does not. Retail's source must give the team value one more counted use, or the template one less, without emitting code.

## Ruled out in this run (all left the 8/16/4 shape unchanged unless noted)

- Calibration (scratch only): one straight-line `g_sink = (int)team` in the arm flips the choice; the same sink inside a nested `if`, a nested `if` before the team definition, or a nested-if sink of the template does not. So the gap is less than one arm-weighted use, and it is not a block-count ratio (the nested `if` before the team definition would have flipped a Chow-Hennessy ratio).
- Team side: inline `Player::getDefaultTeam()` (const and non-const, and one returning `Team *&` copied into a value), `Team *const &` bound to a by-value accessor, a reference local copied into a value local (9 regions), `team` declared without initialiser before the if or at function scope.
- Template side: inline `findTemplate` wrapping `findTemplateInternal`; ZH's `isKindOf` through `TEST_KINDOFMASK(const KindOfMaskType &, t)` with a byte array, a dword array or STLport `bitset` (each keeps the template in EBX and changes the test bytes: the byte-array and `bitset` `test` stay out of line at /O1, and the dword array tests through `shr`); `isHordeTemplate(const ThingTemplate *const &)`; `const ThingTemplate &` and `const ThingTemplate *const &` locals; a non-const template pointer; the template declared at function scope.
