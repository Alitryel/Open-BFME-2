The whole four-body draft is banked at `reverse/attempts/0x00654dc0.cpp`. It was authored from retail, the existing native COFF symbols/relocations and SDK interface declarations; no Microsoft implementation source was read. It is not production source or progress.

The 1571-byte main extent includes both dense switch tables and compressed BYREF maps. `retail-switch-groups.json` records their exact target groupings. The native allocation-only SEH region has a constant-one filter and maps GetLastError through HRESULT_FROM_WIN32. Argument variants are built in reverse order, optional missing variants are trimmed after accounting for named arguments, Invoke uses a null IID and LCID zero, and exception info is handed to the already recovered routine. The null GUID is requested by an explicitly all-zero UUID declaration, not IUnknown's distinct IID. Successful result transfer intentionally has no VariantClear.
