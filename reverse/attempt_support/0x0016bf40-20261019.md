## Tested hypotheses and remaining work

Read every target verdict, the target bank and the cited sibling bank before the first experiment. No target verdict cites a separate attempt-support path. Hypotheses, evidence and refutation conditions were written before each experiment in `build/worker-16bf40/hypotheses.md`.

Successful changes scale corresponding rows of the two weighted matrices together, use one run-count guard per transformation path, define the independent quaternion intermediates in Z/Y/X/W order, store null array entries in explicit else blocks, and load run data before bone data. The compiler-only barrier from the farm bank was removed. These changes reproduce retail's 0xBC frame and initial EDI=this, ESI=zero, EBP=bone allocation. Every existing comment remains verbatim. The arithmetic, bounds, translation omission for normals and pointer advances were manually reviewed against retail; no emulator verification is claimed.

Rejected trials include a member rotation helper (identical output), other independent temporary-definition orders, alternative count-guard lifetimes with worse alignment, and native-order staged accumulators with worse structural/memory/register counts. Some intermediate trials trade one class against another; only the final candidate's strict improvement over the original bank is claimed. All trial sources, unfiltered align output, compiled disassemblies and measurement JSON remain in `build/worker-16bf40/`.

Remaining mismatch: emitted body is 16 bytes too long; the output-minus-second-source spill is at esp+0x14 and reloaded at loop head, while retail uses esp+0x50 and reloads during the weighted Y lane. Stream count is at esp+0x18 rather than 0x14, normals at 0x4C rather than 0x48, and the first matrix starts at 0x1C rather than 0x18. Weighted leaf association and quaternion load/fold scheduling also differ. No newly supported source lever remains after these tests.
