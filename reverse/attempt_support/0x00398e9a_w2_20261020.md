## New findings

1. **The frame order follows object size and post-fold reference weight.** Scratch probes (not landable, they add code) move retail's order into place: padding `pos` to 32 bytes puts flags at retail's -68 with pos below it, and so do six extra reads of `flags` (four are not enough). Both probes also put `this` above `entry`, as retail has it. Up to 28 bytes pos stays above flags (at 28 bytes `this` and `entry` already swap). So the packer ranks objects by something like references per byte, and retail's IL gave `flags` more weight relative to `pos` (or `pos` less) than any spelling tested here. Folded references do not count: four inline `set(bit)` calls (WB shows four BitFlags set calls, bits 8, 10, 11, 9) compile byte-identically to the bank's single `|= 0xf00`.
2. **`/EHs` is not needed.** With the CastleBehavior unit's own `/EHsc` plus the established C++-linkage free (`#define free bfmeUnusedCRTFree`, `#include <cstdlib>`, `#undef free`, `void free(void *);` before the STLport includes, as in `AIDozerManager.cpp`), the object bytes of the body are identical to the bank's. A landing can therefore join an `/EHsc` unit without a flag change. Plain `/EHsc` without that declaration drops retail's state store before `free` and shrinks the frame to E4.

## Hypotheses refuted (each byte-identical to the bank unless noted)

- Callee visibility: visible noinline set destructor or a plain STLport set; visible storage copy and filter constructors (0x003959FA, 0x00395A35); opaque set constructor. An opaque vector constructor only gives the -1 temporary its own slot.
- Local names (all renamed at once), declaration order of pos and flags (moves the memset, slots unchanged), struct-copy pos (worse: movsd), non-POD pos, POD flags, inline accessors throughout.
- Factorial over six WB-derived spellings (temporary -1, `Player *player = NULL` before the set, one controlling-player variable inserted into `set<Player*>`, repeated `weights[index]`, no barrier, struct copy): no combination is closer. Repeated indexing without the barrier costs 3 register differences; other barrier-free forms are worse (ndiff 82 to 102 against 72).
- `throw()` on every callee group (32 combinations), earlier functions in the unit, `/Zi`, `/Z7`, `/Zd`.

## Resumption
