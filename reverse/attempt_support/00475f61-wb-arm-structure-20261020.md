## Conclusion and resumption

Every spelling of the names loop that WorldBuilder permits compiles to the same IL for the template and team, and the only forms that give retail's allocation (the reference binding, a second team use, or extra branches before the team definition) either change the program's bytes or add dead code. A model consistent with all measurements is that cl 7.1 weighs a use that needs a base register (the template's kind test, the reference form's `push [ebx]`) above a use that folds a memory operand (the value team's `push`); the value team has no such use in any natural spelling. No justified statement-level experiment remains. The one untested direction is still the home unit `HordeContainIface11CSlots.cpp`, but its flags, STL prelude and list shim were measured neutral and none of this body's callees is defined there, so nothing predicts a change. Refutation of this conclusion would be any natural value-form spelling that measures 0 register lines.
