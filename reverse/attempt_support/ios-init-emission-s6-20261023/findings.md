## Method

source, ABSOLUTE scratch obj) with ONLY the final source arg swapped to the
scratch, then subprocess.run (verifier-venv python). Rows selected by
csv.DictReader over reverse/functions.csv filtered on the production source
path (never wholesale). Each row verified with
build.compile_function(row, load_symbol_map(), obj) requiring bytes==target,
unresolved empty, PLUS raw symbol extent via read_object_symbol_bytes without
expected_size >= row size (guards the DIR32 bytearray-extension truncation
false pass; all 16 rows show raw==sz exactly). Census enumerates defined
external code symbols (COFF storage==2 in code sections) and scans every
symbol's relocs for scan_not / find_if references.
