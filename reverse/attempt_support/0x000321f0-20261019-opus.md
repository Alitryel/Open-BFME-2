# 0x000321F0 GeneralAllocator heap validator: Opus round (2026-10-19)

Base: the 0.804 bank (26 regions, 1457 B of 1495 B, see `0x000321f0-20261019-w3.md`).
New bank: 14 structural regions, 1473 B, memory 32 / register 25 operand reports.
Compiler: MSVC 13.10.3077, `/O2 /MD` per the bank header. All semantics unchanged.

## Levers that worked (in order)

1. First bin loop: index-based `c`, count kept in memory: 26 -> 24.
2. Binmap check as `bool binbit/nonEmpty; if (!binbit) errors += nonEmpty ? 1 : 0; else if (nonEmpty) errors += binbit ? 0 : 1;`: 24 -> 19.
3. Third loop recomputes `head = &m_binLinks[index << 1] - 8` per iteration: 19 -> 17.
4. Bit31 test as `(((int)size & (int)0x80000000) == 0) && 1` gives retail's
   `and; neg; sbb; inc` (the unsigned spellings give `shr 31; not`): 17 -> 15.
5. Run-walk region search inline with `goto runDone` out of the outer `for(;;)` once
   the run sits in the last 0x10 bytes of its region, `break` when found but not at
   the end: 15 -> 14. A bool helper adds `sbb al,al; inc al`; an int helper also reaches 14.
6. First loop: explicit `link` pointer IV beside `index`, with `c = m_binLinks[index]`,
   `head = (char *)link - 8` and `int count = p == head ? 1 : 0;`. This puts count in
   memory at [esp+18] like retail: 14, fewer memory/register diffs.

## Remaining residue (gg6 = bank)

- Loop 1: our head is a third strength-reduced IV (ebp += 8). Retail derives it
  per iteration (`lea ebp,[edx-8]` after the `p` load), with index in ebp,
  spilled at [esp+14]. Head from index, from link, or declared first: all 14-16.
  The count init is `mov [esp+18],0` plus a conditional `mov 1` in retail; ours uses setcc.
- +0x3ad large-bin ordering block: retail `je xor / jb mov1 / xor; jmp`. Ours is
  inverted (`jae xor`). Fifteen spellings tried (see the w3 handoff and gd* forms): none moved it.
- +0x4c8: retail reloads `level` from [esp+34] before `setg`, a scheduling-only difference.
- +0x539: retail does a dead store of the in-use word (`and edx,1`) into the `level`
  arg slot and never reloads it. Function-scope int/bool/unsigned locals and `level =`
  reuse all keep `test byte ptr`.
- 0x31E60 is still unrowed and needs a declared name before landing.
  Callees 0x31D00/0x32160 live in `Code/GameEngine/Source/Common/System/memory_pool.cpp`.
